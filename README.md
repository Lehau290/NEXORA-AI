## 🤖 3. Đội Ngũ 8 AI Agents Tiêu Chuẩn

1. **AI General Assistant (`general-assistant`)**: Trợ lý thông minh toàn năng, giải đáp đa lĩnh vực, tư duy logic và lập kế hoạch.
2. **AI Coding Agent (`coding-agent`)**: Kỹ sư phần mềm cấp cao, viết clean code, debug lỗi, giải thích thuật toán đa ngôn ngữ.
3. **AI Research Agent (`research-agent`)**: Nghiên cứu khoa học, phân tích dữ kiện, tổng hợp báo cáo và trích dẫn nguồn.
4. **AI Writing Agent (`writing-agent`)**: Bậc thầy ngôn từ, soạn thảo email doanh nghiệp, bài phát biểu, copywriting và bài viết viral.
5. **AI Study Agent (`study-agent`)**: Gia sư tận tâm, áp dụng kỹ thuật Feynman giải thích bài tập, tạo quiz trắc nghiệm và lộ trình học tập.
6. **AI Data Analyst (`data-analyst`)**: Chuyên gia phân tích dữ liệu, đọc hiểu CSV/Excel, tính toán thống kê và mô hình hóa tài chính.
7. **AI Translator (`translator-agent`)**: Dịch thuật đa ngôn ngữ theo ngữ cảnh văn hóa, chuẩn hóa thuật ngữ chuyên ngành.
8. **AI Marketing Agent (`marketing-agent`)**: Chiến lược gia tiếp thị, Go-To-Market, định vị USP, xây dựng phễu khách hàng.

## 🗄️ 4. Cấu Trúc Cơ Sở Dữ Liệu (15 Bảng)

Hệ thống thiết kế theo chuẩn quan hệ toàn vẹn dữ liệu:

1. `users`: Thông tin người dùng, mật khẩu băm, vai trò, gói dịch vụ, avatar, trạng thái kích hoạt.
2. `roles`: Quản lý vai trò (`admin`, `user`) và danh sách quyền hạn dạng JSON.
3. `agent_categories`: Phân loại danh mục Agents (Tổng quát, Lập trình, Nghiên cứu, v.v.).
4. `agents`: Lưu cấu hình chi tiết của từng Agent (System prompt, avatar, model, tools).
5. `conversations`: Các phiên trò chuyện của người dùng với Agent.
6. `messages`: Tin nhắn trong cuộc trò chuyện (User / Assistant), tokens tiêu thụ, citations, feedback.
7. `workflows`: Quy trình Multi-Agent do người dùng khởi tạo kèm mục tiêu và bản tổng hợp.
8. `workflow_steps`: Từng bước thực hiện của các Agent trong quy trình kèm kết quả.
9. `agent_tasks`: Các tác vụ chi tiết được giao cho từng Agent kèm thời gian xử lý.
10. `documents`: Kho tài liệu được tải lên (PDF, DOCX, TXT, CSV, XLSX, MD).
11. `document_chunks`: Các phân đoạn tri thức được bóc tách phục vụ RAG.
12. `favorites`: Quản lý các đối tượng được đánh dấu yêu thích.
13. `subscriptions`: Gói dịch vụ của người dùng và định mức tokens.
14. `usage_logs`: Nhật ký kiểm toán và đo lường lượng gọi mô hình AI.
15. `system_settings`: Cấu hình tham số toàn hệ thống (mô hình mặc định, tên nền tảng, giới hạn sử dụng).

## 🚀 7. Hướng Dẫn Cài Đặt & Chạy Trên Localhost

### Yêu Cầu Môi Trường:
- Python 3.10+ (Đã được cấu hình venv sẵn sàng trong thư mục dự án)
- Bất kỳ trình duyệt web hiện đại (Chrome, Edge, Firefox, Safari)

### Cách Chạy Nhanh Trên Windows:
Chỉ cần nhấp đúp chuột vào file:
```cmd
run.bat
```
Hoặc mở terminal PowerShell / Command Prompt tại thư mục dự án và chạy:
```powershell
.\venv\bin\python.exe app.py
```
*(Trên Windows chuẩn: `.\venv\Scripts\python.exe app.py` hoặc `python app.py`)*

Màn hình console sẽ xuất hiện:
```
Database initialized and seeded successfully.
🚀 Khởi động NEXORA AI tại http://localhost:5000
```
Mở trình duyệt web và truy cập địa chỉ: **http://localhost:5000** để bắt đầu trải nghiệm!

## 🌐 8. Hướng Dẫn Triển Khai Lên VPS / Hosting (Linux)

### Bước 1: Sao chép mã nguồn lên máy chủ
```bash
git clone <repo-url> /var/www/nexora-ai
cd /var/www/nexora-ai
```

### Bước 2: Tạo môi trường ảo và cài đặt thư viện
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Bước 3: Cấu hình biến môi trường
```bash
cp .env.example .env
nano .env # Điền API Keys và cấu hình mong muốn
```

### Bước 4: Khởi chạy nền với Gunicorn hoặc Systemd Service
Cài đặt Gunicorn:
```bash
pip install gunicorn
```
Chạy thử nghiệm:
```bash
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

Tạo file dịch vụ tự khởi động `/etc/systemd/system/nexora.service`:
```ini
[Unit]
Description=NEXORA AI Multi-Agent Platform
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/nexora-ai
ExecStart=/var/www/nexora-ai/venv/bin/gunicorn -w 4 -b 127.0.0.1:5000 app:app
Restart=always

[Install]
WantedBy=multi-user.target
```
Kích hoạt service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now nexora
```

### Bước 5: Cấu hình Nginx Reverse Proxy & SSL (HTTPS)
Thêm file cấu hình Nginx `/etc/nginx/sites-available/nexora.conf`:
```nginx
server {
    server_name nexora.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # Hỗ trợ SSE (Server-Sent Events) streaming mượt mà
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 600s;
    }

    client_max_body_size 32M;
}
```
Kích hoạt SSL miễn phí với Certbot:
```bash
sudo certbot --nginx -d nexora.yourdomain.com
```
